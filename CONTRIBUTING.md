# Contributing to Odelis

Thank you for your interest in improving Odelis.

## Before you start

- Check the existing issues to see whether the idea or bug is already being discussed.
- For substantial changes, open an issue first so the scope can be discussed.
- Keep pull requests focused on one change where possible.

## Reporting bugs and suggesting features

Use the repository's issue forms for bug reports, feature requests, and documentation improvements. For general questions or discussion, use GitHub Discussions if it is enabled.

## Pull requests

1. Create a branch for your change.
2. Make a focused change and update documentation when needed.
3. Test the affected behavior in a browser.
4. Check responsive layouts when changing the UI.
5. Open a pull request using the relevant template and explain what changed, why, and how you tested it.

## Project status and licensing

Odelis is under active development. The repository does not currently provide an open-source license. Do not assume that repository visibility grants permission to reuse, redistribute, or create derivative works from its code. If a license is added in the future, follow its terms.

## Respectful collaboration

Be constructive, respectful, and specific in issues and reviews. Avoid including passwords, API keys, personal data, or other secrets in issues, commits, screenshots, or pull requests.

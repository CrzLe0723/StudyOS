# Odelis

**A space for thought.**

Odelis is a thoughtfully designed personal workspace for learning, planning, and organizing ideas. The goal is to bring study tools and personal organization together in a calm, focused interface.

## Product direction

- **Visual identity:** forest green, warm ivory, restrained typography, generous whitespace.
- **Core workspace:** overview dashboard, planner, notes/library, and learning tools.
- **Design principle:** clear and useful before clever; the interface should stay quiet so the user's work stays central.
- **Build approach:** start with a useful responsive web app, then add persistent accounts and cross-device data when the core experience is established.

## Development

The current repository contains an early single-file HTML prototype. We will evolve it incrementally, preserving working functionality while aligning it with the Odelis identity.

## Planned milestones

1. Establish the Odelis visual identity and responsive dashboard.
2. Organize the app into clear areas: Overview, Planner, Notes/Library, and Learning.
3. Improve accessibility, mobile layout, and empty states.
4. Introduce a modern component-based stack when it provides clear value.
5. Add authentication and cloud persistence after the core experience is stable.

## Status

Early prototype — actively being shaped.
